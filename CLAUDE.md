# Claude Repository Map

Start with [AGENTS.md](AGENTS.md). It is the tool-neutral repository map.

The current architecture is documented in [ARCHITECTURE.md](ARCHITECTURE.md), all
supported setup and development commands in [docs/development.md](docs/development.md),
test selection in [docs/testing.md](docs/testing.md), and accepted legacy failures in
[docs/technical-debt.md](docs/technical-debt.md).

Do not infer current behavior from historical release notes. When code changes a
command, boundary, configuration key, or known debt item, update its canonical
document in the same commit.
