# 使用

本文说明 `v1.0.0-preview` 的当前 Web 使用流程；返回[文档目录](../README.md)。

1. 打开 `/login` 登录；首次使用先到 `/settings` 的“配置管理”完成模型和数据源设置。
2. 在 `/analysis/single` 提交单只股票分析，或在 `/analysis/batch` 批量提交。进度和已完成
   任务在 `/tasks` 查看。
3. 在 `/reports` 浏览报告并打开详情；在 `/screening` 筛选股票，在 `/favorites` 管理自选股。
4. 在 `/paper` 使用模拟交易。真实投资组合的持仓、成交记录和导入历史位于
   `/portfolio/real-holdings`、`/portfolio/real-transactions` 与 `/portfolio/imports`。
5. 在 `/learning` 浏览学习中心内容。

分析结果用于学习和研究，应结合独立判断与风险管理。遇到运行问题先看[故障排除](troubleshooting.md)。
