# 600519（贵州茅台）价值投资取数够用度实测

- 日期：2026-06-24
- 标的：600519 CN，报告期 2025-12-31
- 提取方式：force_refresh + codex 订阅 token 穿透（deep=gpt-5.5）→ 上游归一 → 下游 turtle `report_adapter` 消费 normalized_value/canonical_unit
- 关联：PR #35（FRC 缓存读取/跑 LLM 解耦）、`00003_value_normalized_value_cache_and_debug`、上游 money-unit-normalization-funnel
- 用途：验证 PR #35 修复在新标的端到端生效，并盘点价值投资取数缺口

## 1. 结论

`TurtleFacts.status = degraded`（**可决策、非 `non_decisionable`**）。价值投资主线数据足够；精细自由现金流 / owner earnings / 多年派息平滑受少数字段缺失制约。

- **主体价值判断（盈利、现金流、分红回购回报、负债结构）：够。** 三大报表主干 + 分红/回购/派息核心字段全部 `reliable`、已归一 CNY。
- **精细估值（FCF / owner earnings / 多年派息）：不够**，主因折旧摊销缺失 + 派息率仅单年代理。

## 2. PR #35 修复在 600519 上的三段验证

| 场景 | 结果 | 验证点 |
|---|---|---|
| CACHE miss + 无 codex | `available=True` + warning「retried provider-only」 | 解耦 + P2 重试不崩溃，provider 字段齐全 |
| force_refresh + codex 穿透 | 分红 672.4亿 / 回购 61.2亿 / 派息率 0.817 全 `reliable` | 完整 LLM 提取 + normalized 消费链 |
| CACHE_FIRST 无 deep-env（修复主路径） | `dividends_paid normalized_value=67241733345.45 CNY` 直接读到 | **本次修复核心**：CACHE 命中读 DB 的 LLM normalized，无需 force/codex/清缓存 |

## 3. 核心字段（reliable，已归一 CNY）

- 利润表：`revenue`、`operating_cost`、`operating_profit`、`net_profit`(823.2亿)、`invest_income`、`non_oper_income/exp`、`rd_exp`、`selling_general_administrative`
- 现金流量表：`operating_cash_flow`(615.2亿)、`investing_cash_flow`、`capex`(31.3亿)、`interest_paid_cash`
- 资产负债表：`total_assets`(3038亿)、`total_liabilities`、`total_cur_assets`、`total_cur_liab`、`inventories`、`st_borr`、`lt_borr`、`interest_bearing_debt`、`minority_int`、`cash`
- 价值核心：`dividends_paid`(672.4亿)、`buyback_amount`(61.2亿)、`dividend_payout_ratio_current_year`(0.817)

## 4. 缺口（16 个 caveat，影响排序）

| 字段 | caveat 原因 | 对价值投资影响 |
|---|---|---|
| `depreciation_amortization` 折旧摊销 | unresolved_conflict | **较关键**——FCF / owner earnings / EBITDA 都需要它，优先补抽 |
| `dividend_payout_ratio` 单年 | single-year proxy | 仅单年代理值、**非 3 年均值**，海龟模型多年平滑会偏 |
| `stock_based_compensation` 股权激励 | unresolved_conflict | 调整真实盈利质量；茅台此项小，影响有限 |
| `gross_profit` 毛利 | display_only（unresolved_conflict） | 毛利率分析降级；可用 `revenue - operating_cost` 自行派生 |
| `dps` 每股股息 | unresolved_conflict | 可由 `dividends_paid ÷ 总股本` 派生 |
| `restricted_cash` 受限现金 | unresolved_conflict | 真实可动用现金有偏差 |
| `capitalized_interest` 资本化利息 | unresolved_conflict | 真实利息支出 / 资本开支调整 |
| `segment_revenue_profit` 分部 | unresolved_conflict | 业务结构分析（茅台单一为主，影响小） |
| 其余 | unresolved_conflict / source_unavailable | `amounts_due_from_subsidiaries`、`contract_liabilities_non_current`、`dividend_policy_text`、`lease_liability_maturity`、`receiv_tax_refund`、`receivables_aging`、`time_deposits_or_wealth_products`：精细附注项，主线分析非必需 |

> 注：`LLM supplement from gpt-5.5 allowed by policy` 不是缺失，是 LLM 补充字段被策略放行的正常提示（字段仍 `reliable`）。

## 5b. value 决策层实际阻断（compute_turtle_signals）

§3/§4 是**取数层**字段覆盖；本节是**决策层**——跑完整 value 流程（`prepare_turtle_analysis_payload` → `compute_turtle_signals`）后，哪些价值公式真正被阻断。

**关键：`signals.status = non_decisionable`（比 `facts.status = degraded` 更严重）。** 即分红字段已修好（PR #35），但 value 最终决策仍被阻断。

| 公式 | status | value | 阻碍输入 |
|---|---|---|---|
| `R`（核心回报率） | **non_decisionable** | None | `tax_rate`、`buyback_amount_3y_avg` |
| `GG` | **non_decisionable** | None | `tax_rate`、`buyback_amount_3y_avg` |
| `HH` | **non_decisionable** | None | `tax_rate` |
| `payout_M` | degraded | 0.817 | `dividend_payout_ratio_current_year_3y_avg` |
| `owner_earnings` | ✅ complete | 583.9 | — |
| `net_cash_ratio` | ✅ complete | 3.42 | — |
| `ev_switch` / `cash_protection` | ✅ complete | 0.0 / 30.0 | — |

**缺失输入聚合（按阻断公式数）**：

1. **`tax_rate` — 阻断 3 个公式（R/GG/HH）**：最大瓶颈。来自 `market_adapter`（非 FRC 抽取），caveat 为 `tax_rate uses default holding_channel 'long_term_domestic' for A; pass holding_channel explicitly` + `tax_rate unreliable: display_only`。**与分红链路无关，是独立的税率取数/配置问题**——A 股默认 holding_channel 的税率被判 display_only，导致税后回报率公式整体不可决策。
2. **`buyback_amount_3y_avg` — 阻断 2 个（R/GG）**：回购 3 年均值缺失（只有单年报告、无历史多期），caveat `treated as 0 for degraded calculation`。
3. **`dividend_payout_ratio_current_year_3y_avg` — 阻断 1 个（payout_M 降级）**：派息率多年均值缺失，回退单年代理。

**结论**：解除 600519 的 `non_decisionable` 需先解决 **`tax_rate`**（独立于 FRC，市场适配层的税率可靠性），其次补**多年历史期**以算 3 年均值。折旧摊销（§4）影响精算但不阻断决策。

### 更新（2026-06-25，tax_rate 已解除）

`market_adapter.py` 的 tax_rate 可靠默认化改造（spec `docs/superpowers/specs/2026-06-24-hk-cn-tax-rate-reliable-default-design.md`）落地后，A股默认渠道 `tax_rate=0` `reliable`（无 caveat）、港股通默认 20% `reliable`+caveat。600519 实测前后对比：

| 公式 | 改造前 | 改造后 |
|---|---|---|
| `signals.status` | **non_decisionable** | **degraded** |
| `R` | None（缺 tax_rate + buyback_amount_3y_avg） | **4.44**（仅缺 buyback_amount_3y_avg） |
| `GG` | None | **3.15**（仅缺 buyback_amount_3y_avg） |
| `HH` | None（缺 tax_rate） | **1.29**（完全 complete，无缺失） |
| `market.status` | degraded | **complete** |

`tax_rate` 不再出现在缺失聚合中，R/GG/HH 全部算出数值，`HH` 完全解除，`market` 转 complete。**整体决策从不可决策（non_decisionable）跃升为可决策但降级（degraded）**。

**剩余阻断收敛为多年均值缺口**（与税率/分红无关）：`buyback_amount_3y_avg` 阻断 R/GG、`dividend_payout_ratio_current_year_3y_avg` 使 payout_M 降级——均因只有单年报告、缺历史多期。下一步若要进一步收敛，方向是补**多年历史报告期**以算 3 年均值。

## 6. 优先补抽建议

1. **`depreciation_amortization`**：价值投资 FCF/owner earnings 的硬需求，`unresolved_conflict` 需上游消歧或下游从现金流量表附注派生。
2. **多年派息率**：当前单年代理，需上游提供或下游聚合多期 `dividends_paid/net_profit` 算 3 年均值。
3. `gross_profit` / `dps`：可在下游用已 reliable 字段派生，优先级低于上游补抽。

其余 `unresolved_conflict` 字段与 `00003 §3` 的 603345 缺口同源（上游抽取多处数值冲突无法定论），单独跟进。
